China city offline basemap (china_city.gpkg)
============================================

Purpose
-------
Engineering / developer default map for SmartGis Views (prefecture-level
area, major rivers and trunk roads as lines, city points, Chinese text
anchors). Not a survey product and not for official cartographic publication.

Layers
------
area, line, point, text  — CRS EPSG:4326 / OGC CRS84

line.kind: river | lake | road
line.class (roads): motorway | trunk | primary  (OSM-like tags for MapScene)

Also produced: china_city.geojson (same features, single FeatureCollection with
kind=area|line|point|text; roads use line_kind=road + class=) for hosts that
still probe .geojson before .gpkg.

Sources
-------
1) Prefecture (地级) administrative polygons
   - Aliyun DataV GeoJSON API (areas_v3)
   - Base: https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json
   - Per-province children: https://geo.datav.aliyun.com/areas_v3/bound/{adcode}_full.json
   - Direct-controlled municipalities / SARs / Taiwan kept as single province
     polygons; other units use DataV `level=city` features.
   - License / terms: follow Aliyun DataV / 高德相关开放平台数据使用说明；
     redistribution of derived offline demo packages for non-commercial
     engineering use is common practice for this public endpoint — verify
     current terms before shipping a product basemap.

2) Line layer — rivers / lake centerlines
   - Natural Earth 10m rivers and lake centerlines
   - https://www.naturalearthdata.com/
   - https://naciscdn.org/naturalearth/10m/physical/ne_10m_rivers_lake_centerlines.zip
   - License: public domain (Natural Earth)

3) Line layer — national trunk roads (China bbox clip)
   - Natural Earth 10m roads (Major Highway + low-scalerank Unknown/Road)
   - https://naciscdn.org/naturalearth/10m/cultural/ne_10m_roads.zip
   - Mapped to kind=road, class=motorway|trunk|primary for MapScene styling
   - Simplified cap (~1500 road features) for repo size
   - License: public domain (Natural Earth)

4) Point / text
   - Derived from area centroids / DataV center fields; `anno` holds Chinese
     labels for leftover Anno-compatible painting.

Build
-----
  py -3 testing/data/build_china_city.py
  py -3 testing/data/build_china_dem.py

Caches downloads under out/china_city_src/. Writes testing/data/china_city.gpkg
and copies to out/china_city.gpkg. See china_city.PIN.txt for SHA-256.

china_dem.tif
-------------
Country-wide Float32 elevation grid (EPSG:4326) for leftover / Views 3D.

Default build (real DEM):
  py -3 testing/data/build_china_dem.py
  Source: AWS Open Data elevation-tiles-prod GeoTIFF tiles
    https://s3.amazonaws.com/elevation-tiles-prod/geotiff/{z}/{x}/{y}.tif
  (Mapzen / Nextzen terrain stack: SRTM, GMTED2010, NED, ETOPO1 and related
  public elevation layers; see https://github.com/tilezen/joerd ).
  Land outline cutline from DataV national boundary JSON when available.
  Tile cache: out/china_dem_src/

Offline fallback:
  py -3 testing/data/build_china_dem.py --source synthetic

Forbidden uses
--------------
Do not present this package as an official national boundary dataset or as
having a surveying / mapping publication number (审图号).
Do not present china_dem.tif as a surveyed cadastral product; it is an
engineering demo mosaic of public elevation sources.
