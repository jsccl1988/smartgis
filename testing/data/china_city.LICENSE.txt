China city offline basemap (china_city.gpkg + china_dem.tif)
============================================================

Purpose
-------
Engineering / developer default map for SmartGis Views:
  - vectors: area / line / point / text
  - elevation: china_dem.tif for leftover / Views 3D

Not a survey product and not for official cartographic publication.

CRS
---
All layers: EPSG:4326 / OGC CRS84 (WGS84 lon/lat).
Do **not** mix GCJ-02 admin (e.g. Aliyun DataV) with WGS84 rivers/roads/DEM.
Ignore any leftover `china_city.LICENSE_migrated.txt` — that filename described
the old mixed pack and is not the current source of truth.

Rivers and roads come from committed China extracts
(`china_hydro.src.geojson`, `china_roads.src.geojson`). The build script does
**not** download or clip the global Natural Earth river/road shapefiles.
长江 is one merged stem (Jinsha / Chang Jiang / mouth) reaching ~121.5°E.

Layers (china_city.gpkg)
------------------------
area, line, point, text

line.kind: river | lake | road  (style: line-water vs line-road)
line.class (roads): motorway | trunk | primary  (OSM-like tags for MapScene)

Admin overview: mainland provinces; Taiwan / Hong Kong / Macao dissolved to
one silhouette each. Paracel (西沙) is omitted so the pack stays inside
the 18°N framing bbox.

Also produced: china_city.geojson (same features, single FeatureCollection with
kind=area|line|point|text; roads use line_kind=road + class=) for hosts that
still probe .geojson before .gpkg.

Sources (aligned pack)
----------------------
1) Land / admin / places — Natural Earth 10m cultural (public domain)
   - https://www.naturalearthdata.com/
   - admin_1 states/provinces and populated_places (CHN/TWN/HKG/MAC only)
   - EPSG:4326 / CRS84

2) Hydrology and roads — China extracts in this directory (same CRS)
   - testing/data/china_hydro.src.geojson  (kind=river|lake)
   - testing/data/china_roads.src.geojson  (kind=road, class=motorway|trunk|primary)
   - Frozen China network (not a runtime clip of the global NE river/road zips).
     Rebuild does not download `ne_10m_rivers_lake_centerlines` / `ne_10m_roads`.

3) Elevation — AWS Open Data elevation-tiles-prod GeoTIFF
   - https://s3.amazonaws.com/elevation-tiles-prod/geotiff/{z}/{x}/{y}.tif
   - Mapzen / Nextzen terrain stack (SRTM, GMTED2010, NED, ETOPO1, …)
   - Warped to EPSG:4326; land cutline from NE admin_1 outline
     (testing/data/_china_ne_outline.geojson)

Build
-----
  py -3 testing/data/build_china_city.py --with-dem
  # or separately:
  py -3 testing/data/build_china_city.py
  py -3 testing/data/build_china_dem.py

Caches: out/data/cache/china_city_src/ (NE admin/places + outline),
out/data/cache/china_dem_src/ (tiles). Hydro/roads are vendored next to this
LICENSE. Writes testing/data/china_city.gpkg (+ .geojson) and china_dem.tif;
copies under out/data/. See china_city.PIN.txt for SHA-256.

Offline DEM fallback:
  py -3 testing/data/build_china_dem.py --source synthetic

Forbidden uses
--------------
Do not present this package as an official national boundary dataset or as
having a surveying / mapping publication number (审图号).
Do not present china_dem.tif as a surveyed cadastral product; it is an
engineering demo mosaic of public elevation sources.
