# MapFrame CPU layout — Implementation Plan


> **Design living:** [../specs/2026-09-27-map2d-frame-design.md](../specs/2026-09-13-render-rhi-scene-design.md) living. This file is the checklist only.

**Status:** active  
**Spec:** [`../specs/2026-09-27-map2d-frame-design.md`](../specs/2026-09-13-render-rhi-scene-design.md)

**Note (2026-09-27):** RHI Pass physical tree is **`src/effect/map`** (`effect::map`), not `src/render/map2d`. CPU side is `src/gis/vista/frame`. Section 2 path below is historical; do not recreate `render/map2d`.

三个所有权区。本计划只落地 gis 布局；render pass 与 Views 接线留给对应 agent。不要把逻辑写进 `GpuScene::rebuild_meshes`。

## 1. gis::map2d layout（本变更）

- [x] `src/gis/map2d/frame.h`：`Layout::build(LayoutInput, vector<LayerBatch>)`、`MapFrame`、`DrawItem`、`default_carto_style_json`
- [x] `LayoutInput::symbols`（icon / fill-pattern 像素尺寸）；`DrawItem::anchor_x/y`；`kRaster` 的 `codepoint` = `texture_key`
- [x] 按样式文档顺序画 background / raster / fill / line / circle / symbol
- [x] fill / line 调用 `gis::tessellate_geometry` / `gis::tessellate_line`
- [x] circle 为世界单位三角扇（> 4 顶点）
- [x] `gis::map2d::detail` 移植 collision：priority、LOD、budget、halo、label box、沿线切线、空间哈希
- [x] `ResolvedPaint` 增加 `symbol-placement`、`text-halo-color`、`text-halo-width`（仅常量）
- [x] `default_carto_style_json()`：land / water / river / road casing+fill / admin / labels
- [x] `map2d_test` + `style_test` 新键
- [x] `//src/gis:gis` 编入 `map2d_sources`；`test_shell` 挂上 `map2d_test`

## 2. effect::map::Pass（另一 agent；终态 `src/effect/map`，曾计划 `src/render/map2d`）

- [x] 消费 `MapFrame`，不 `#include` legacy，不把调色板写进 pass
- [x] background：用 `background_rgba` × `background_opacity` 清屏，不要画成 mesh
- [x] `kRaster`：世界 lon/lat 四边形，`u/v` 0..1（`v = 0` 为 `max_y`），纹理键读 `codepoint`
- [x] `kFill` / `kLine` / `kCircle`：世界坐标网格，`pixel_space == false`；fill 的 `symbol_id` 非空时采样 pattern，否则纯色
- [x] `kIcon`：`symbol_id` + `u/v` 0..1，像素空间，绕 `anchor_x/y` 转 `angle_rad`
- [x] `kText`：每 codepoint 一个轴对齐四边形（`u/v` 为 0），同一 `angle_rad` 与锚点；晕圈用 `halo_width_px` / `halo_rgba`。Windows 字形光栅在本 pass，不在 gis
- [x] 颜色 `0xAARRGGBB`，再乘 `opacity`

## 3. Views 接线（另一 agent，`src/app`）

- [x] 按 `source-layer` 组 `LayerBatch`（`map2d/frame/map2d_batches`）
- [x] 填 `LayoutInput` + `Layout::build` + `effect::map::Pass`（`Map2dPresenter::present_gpu`）
- [x] 缺 icon / metrics 行为由 vista Layout 锁定；空帧保留背景
- [x] 不在 `GpuScene::rebuild_meshes` 里复制这套布局

## 4. Perf dual-speed + visual alignment（§Perf 2026-09-28）

Phase 1（性能）:

- [x] `Map2dPresenter` 缓存 `MapFrame` + content fingerprint + zoom-bucket
- [x] interactive：相机变、zoom-bucket 不变 → 复用世界项 present
- [x] settle：交互刚停 → 完整 rebuild
- [x] 静止重复 present → 跳过 `Layout::build`
- [x] `layout_build_count` / `invalidate_frame_cache` + `map2d_presenter_test` 覆盖
- [x] 确认默认 GPU 主路径（living § + `map_pages` 既有 env 降级）

Phase 2（视觉 A→C→B）:

- [x] 线面 AA / 宽度 / dash / 半透明（`effect::map` feather + textured tint；`map2d_pass_test`）
- [x] Style JSON 主路径；「渲染参数」表降级（FeatureInfo Style 区；sidecar `.style.json`；legacy 标明 debug）
- [x] 注记 halo / 碰撞 / 沿线字观感（vista：弧长中点、halo 碰撞盒、`river-label`、map2d_test）

**Deferred / known gaps:** RHI MSAA；`text-color` → ResolvedPaint；MapLibre 沿线重复 placement；glyph PBF；`interpolate`。

## 5. MapFrame-unified software present（§ 同名，B/B2/C1/D2，一次替换）

- [x] `map2d/frame/map2d_frame_cache.{h,cc}`：从 `Map2dGpuPresent` 抽出 fingerprint + dual-speed；`ensure_full` / `prepare_for_present`

- [x] D2：`visible_layer_batches(..., scale)` 用 carto importance / line visibility 过滤
