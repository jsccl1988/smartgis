迁入 content

src/content/browser/glang.runtime/

language ir exec host

  • language/：front → sema → lower → app::code。不含 IR。
  • ir/：车道头文件同层；ir/gis/ 是扁平模块（verb、measure、transform、feature、host、construct、write）。
  • exec/：op、eval、extend，以及 exec/session 里的解释器。
  • host/ 通过 content::Shell / content::Pane（均为 detail::Op 袋，无虚表）填 CapabilityHost。不包含 Browser、DrawHost、PluginShell。
  • GN :backend 与 :session 不依赖 //src/app/views。

壳侧只从外部 bind

app/views/app/startup/shell_runtime.cc

Shell Op袋 Browser

  • 把 Browser / DrawHost / PluginShell 填进 Shell 与 Pane 的 Op 槽（无虚适配器）。
  • 然后调用 content::run_suite_script。
  • 这里没有 host/，也没有 exec/session。控制台任意 :py 仍是壳内嵌入式 CPython。

依赖边

禁止 content 不 #include app/views，GN 也不依赖 //src/app/views。
允许 app/views 的 shell_runtime 从外部 bind，再进入一个 content public 入口；content 内 eval 使用 CapabilityHost。host/ 与 exec/session 在 glang.runtime。

头文件 src/content/public/script_runtime.h。签名是 content::run_suite_script(CapabilityHost&, std::string_view, std::string*)，没有额外方法。

允许的调用顺序

1 套件脚本

作者编写的 .py。下沉之后由 content 内编译器处理。

2 壳侧 bind

app/views 填充 content::Shell，把 Browser 槽写入 CapabilityHost。

3 唯一入口

content::run_suite_script。public 只此一个函数。

4 content eval

content/browser/glang.runtime/exec/eval 按 app::code 执行。

5 CapabilityHost

app::ir 标准库落在已 bind 的槽上。

箭头只从壳侧进入 content。content 不回头包含 app/views。
