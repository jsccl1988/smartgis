content/browser — 责任层与子目录

Chromium-style content 层：嵌入方只含 public/。C10 已按职责拆目录； C11 收紧薄同级（并入 contents/ + session/，拍平 document/）。 content.dll 不含重 present/GDI；Views 另链 :browser_session。

Spec：§Content sink · 收紧：§Content browser subdirectory tighten · As-built：src-layout · 进程：§Content process layers · 模块：browser/README.md
相关图： 嵌入面 content-embedder Views shell Map2d present DebugAgent

1. 核心分层（谁拥有什么）

public/（锁定嵌入面）

  • 9 个头：MapContents / observer / types / EventBus / ViewHost / PluginHost / catalog / attrs / bootstrap
  • 不拥有：present、GDI、BrowserSession
  • 物理路径不随 browser 子目录移动

content.dll TUs

  • C11：全部进 contents/（MapContents + bootstrap/catalog/attrs/plugin 实现）
  • C10 过渡目录 bootstrap/ catalog/ attrs/ plugin/ 删除
  • 例外：present/scene3d/session/scene3d_rhi_session（CONTENT_EXPORT）

:browser_session（Views/exe）

  • session/ 拥有 document/camera/present + 手势 + MapContents*
  • document/ MapScene（C11：helpers 平铺，无 store/ingest/… 子目录）
  • camera/ 2D 视口 + 3D 轨道
  • C11：input/ 并入 session/

present / debug（不进 DLL）

  • present/map2d|scene3d/{frame,gpu,software}
  • GDI 只在 */software/；render ↛ content
  • capability/ IL Host；debug/ DebugAgent

无转发头。会话头只在 session/browser_session.h。

4. 进程泳道（browser / renderer / gpu）

产品默认停在进程内 browser，不等待子进程。公开面见 content-embedder.html。 不打开 ENABLE_OOP_RENDER。无 Mojo。 MapContents 不与 BrowserSession 合并。不做 C11 目录拍平。 C6 不变：重 present/GDI 不进 content.dll。 utility（GDAL/IO）不实现。

browser（默认，进程内）

  • app：壳、面板、消息循环；china_product_defaults.cc 留在 app
  • content/browser：文档、相机帧、present 调度、手势、DebugAgent（不进 public）
  • content/browser/child 的 ChildProcessHost：同一 PE、--type=、--parent-pid=、--pipe=、Job KILL_ON_JOB_CLOSE、等 Hello

renderer（OOP 打开后才拆）

  • 今天走 invitation，启动路径不拉起
  • 稍后改到同一 host_protocol；OOP 打开时由 content 拉起
  • 拆开之后：文档、工具、命中
  • 不引入 Mojo

gpu（只画）

  • 现在：GPU 启动统一进 ChildProcessHost；行为不变
  • GpuMain 留在 src/gpu
  • vista/scenic 的网格、晕渲、大气留在下层；content present 只调度
  • 重 present/GDI 不进 content.dll
1 · 现在统一 GPU 启动到 ChildProcessHost。行为不变。
2 · 稍后renderer 从 invitation 改到 host_protocol。不引入 Mojo。
3 · 仅 OOP角色才拆进程。browser 留 chrome 与共享表面；renderer 持文档、工具、命中；gpu 只画。
4 · 不实现utility（GDAL/IO）仍不做。
