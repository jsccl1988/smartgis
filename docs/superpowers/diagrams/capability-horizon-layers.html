capability/horizon 分层

目录按编译相位切开，动词按 IL 语法接槽（execution/sema/horizon.cc + 仍由 horizon 拥有的 document / input / showcase 槽）。 抓图走 capture，断言走 expect。命名空间 app::detail。atom 不包含 sema。

1. 层（谁拥有什么）

bind — 链接

  • bind/bind_horizon 按语法接槽：pump / tabs / mark / window / key / inject / paths / document / china / stress / still / ui。
  • wait_ready、expect_*、activate_tool 不在这里接，由 expect/bind 填。

sema — 语义（编排 capture / expect）

  • still：browse 静帧。Map2d 调 capture/sema/export（不 invalidate）；Scene3d 调 atom/paint + sema/gate + sema/read。
  • china：打开样本并种图。 document：style / clear / fit / invalidate / edit dispatch。
  • ui：主题、面板、layout gate、shell BMP（GDI 仍用 capture atom + gate）。

atom — 原子操作

  • pump 抽消息。surface 一次 HWND 注入 / resize。paths 解析 exe 旁路径。
  • stress 一次 pan/wheel 爆发（browse_stress）。

沉淀到同级 pack

  • capture：BMP、HWND 读回、软件 paint、停表 / detach。
  • expect：wait_map_ready / viewport / geom / wheel-cursor / layout / DebugAgent。

2. 原理流（browse still）

bind 只填槽。pump / HWND 注入是 horizon atom，因为语法动词是 window / key / pump，不是 BMP。
