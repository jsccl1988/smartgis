Catalog 2D / 3D ↔ Map / Scene3d

同一 GisDocument；两个 CatalogView；外层 2D|3D 与 Map|3D 双向同步。

分层

2D 车道

  • catalog_2d_ — Layers / Sources / Maps
  • 过滤：carto 全量（含 hillshade / basemap）
  • 可见性 → invalidate_map2d_frame_cache
  • 配对 map_tabs_[0] Map
catalog_mode_tabs_
⟷
map_tabs_

3D 车道

  • catalog_3d_ — 同结构 TOC
  • 过滤：land-surface affinity
  • 可见性 → invalidate_native_scene + request_frame
  • 配对 map_tabs_[1] 3D
Document — 共享 BrowserSession::document_layer_descs()； detail::filter_layer_descs_for_mode 在壳侧过滤（不改 content/public）。

原则流

1. 用户点 Catalog「3D」 → on_catalog_mode_changed(1) → catalog_ = catalog_3d_ → switch_map_tab(1)
2. 用户点 Map「3D」 → switch_map_tab(1) → on_map_tab_changed(1) → catalog_mode_tabs_ → 3D

防重入：CatalogComposer::syncing_mode_；TabStrip::set_active 不触发 change_。
