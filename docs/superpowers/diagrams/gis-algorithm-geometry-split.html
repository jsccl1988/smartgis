算法层 ↔ 几何体层 — 依赖分离

几何体拥有类型与存储；算法是纯 ops + backend traits，只依赖 concept，绝不反向被 mesh 头引用。

Living：2026-09-13-algorithm-layer-oss-design.md §4 分离契约（补图）· 主分层图：gis-geo-layers.html

1. 核心分层（职责对照）

几何体层

  • OGC：OGRGeometry / OGRTriangulatedSurface
  • Mesh：geo::Grid（2D 缓冲）；Tin 弃用门面；3D hex → 插件 HexLattice
  • 属性：envelope、实例 coordinate_dimension
  • Traits 描述：geometry_traits / ogr_geometry_like
  • 薄 codec：as_ogr / clone_ogr
  • 路径：gis/geo/ops/
算法 → 几何体
允许 include / 写出
几何体 → 算法
禁止反向依赖

算法层

  • Ops：geo::buffer（GEOS/OGR）
  • TIN：geo::delaunay（GEOS）
  • Grid：geo::solve_laplace / solve_elliptic / compute_orthogonality
  • PROJ：geo::CoordinateTransform
  • Analysis：native.* / OpsRunner / Eigen；地形烘焙核 horn_lambert_shade / fill_ring_mask
  • 依赖 concept，不拥有结点表
  • 路径：gis/geo/ops/ · gis/geo/{tin,grid,proj} · analysis/**
