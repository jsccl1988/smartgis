1b. 3D 对等轨：scene3d 不下沉 rhi3d/impl/common

2D 制图挂在 rhi2d/impl/common/paint，因为 Scenic 没有独立 map 场景图。3D 有对象图，对等 vista/scene。把 scene3d/ 搬进 rhi3d/impl/common 会让设备层 #include Object3d / Scene。

2. rhi2d — CPU 光栅并行（私有 HDC）

Raster×N 在工人私有 HDC 上执行，汇合后 BitBlt。GPU 上传、Compute 与 CommandList 在 Vista 的 FlyCube 路径上。

3. rhi3d — CPU Prep×N，GPU 在设备上画

Prep×N 只做视锥 AABB，工人不做 GL/D3D Draw。GPU 加速发生在下一步：GL 串行 Draw，或 D3D11 deferred 的 Finish → Execute。HWND 不 join FrameJob。

4. 与 Vista：同一帧的两边

当前代全图：Vista — 逻辑对象 / 物理录制。Scenic 的 rhi2d/rhi3d 设备留在本引擎内；Vista 的设备是 src/render 的 FlyCube。取舍全文在规格 §Vista logical/physical lanes。
