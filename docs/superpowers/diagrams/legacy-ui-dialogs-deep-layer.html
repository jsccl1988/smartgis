legacy/ui/dialogs 深度分层（§11i）

语义对齐 ui/views/dialogs + ui/gis/{catalog,inspect} 产品模态；物理仍在 src/legacy/ui/dialogs。Scheme C，无 shim。

api 导出门面

dialogs_api → Smt*Dlg / SmtGetActiveWnd；调用方只含此头

toolkit 通用模态（≈ views/dialogs）

input_text_dialog select_one_dialog ← 无 GIS 类型；CDlg* + IDD

gis 产品模态（≈ gis/dialogs）

feature_info_dialog att_struct_dialog → AttributeSchema ← SmtFeature / OGRLayer

detail 组合辅助

ogr_field_type feature_info_grid ← 标签映射 / 属性网格填充；对话框只装配

inspect（邻能力，已剥离）

config_dock_bar edit_config_dock_bar → inspect_sources，不再编进 dialogs
原则流
  1. 调用方 → dialogs_api → toolkit / gis 对话框；不直含 CDlg* 头。
  2. OGR 字段标签与 Feature Pack 网格填充下沉 detail/，对话框只做 DoModal 装配。
  3. inspect 码头属 inspect/，与模态对话框能力分离。
  4. 终局 Views 不依赖本树；本波不出 legacy/；冻结 Smt*Dlg / CDlg* 名。
