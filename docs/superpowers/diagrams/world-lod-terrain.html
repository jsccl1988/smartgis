Vista — World LOD Terrain

CPU component/world/terrain 产出 TerrainPayload；设备线程 TerrainPass 由 WorldPass 组合。raster / TIN / surface-interp 共用上传与 record。

Spec：§Vista world LOD terrain component+pass · terrain README
相关图： Vista 子目录分层 DEM bake

1. 核心分层

vista/terrain — bake

  • DemRaster / hillshade / land_mask
  • DemHeightField::sample / build_mesh
  • 不持 World；不 include WorldPass

IR — component/world/terrain

  • TerrainPayload 嵌在 Node / Instance
  • policy：max_edge · TIN stride · cache key · morph
  • grid：nested 环 + edge skirts
  • seed TU：raster / nested / surface / TIN
  • assert_no_deps render

Pass — pass/world

  • WorldPass::sync_from / record_draws
  • 组合 TerrainPass（upload + solid gate + kTerrain）
  • content 只持 WorldPass

2. 原理流（seed → sync → TerrainPass → record）

阶段高亮循环表示「谁产出、谁上传、谁录制」——CPU seed 永不 join 设备线程。
