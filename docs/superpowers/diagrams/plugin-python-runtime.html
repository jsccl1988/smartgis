glang 拥有 CPython · plugin + ext

进程内一个解释器：content::py::Interpreter。PythonRuntime 在 plugin/runtime/extension。Host / ui / gis 装在 glang.plugin（exec/session/embed）。第三方 import glang.ext.<plugin_id>。plugin/runtime/python 已删除。

分层（谁拥有什么）

脚本 / samples

  • import glang.plugin（核心）
  • import glang.ext.<id>（扩展）
  • 新样品：plugin/runtime/samples/
  • 样品在 plugin/runtime/samples/

glang.runtime · 解释器

  • content::py::Interpreter
  • install_glang_plugin + install_glang_ext
  • mount_extension / unmount_extension
  • Debug 为桩（不链 python312.lib）

glang.plugin + glang.ext

  • 核心：register_fn → eval_*
  • 扩展：包内 ext/ 或 ext.py
  • 可选：register_extension_fn
  • id == plugin.json id

插件运行时

  • extension/runtime：PythonRuntime
  • extension/bind：start 前 mount
  • stop 后 unmount
  • 不调用 Py_Initialize
  • Host 贡献点仍走 PluginHost

停用：先 unmount 扩展，再卸插件模块；进程退出才 Py_FinalizeEx。门禁：ext_module_test。
