plugin/runtime/python：进程内 CPython + L2 宿主缝

一样本目录 → 多样本包。Chrome 只持有一个解释器；每个 kind=python 包按目录独立 start/stop。内核仍在 C++。

分层（谁拥有什么）

UI · Views / chrome

  • smartgis.ui 控件与 picker
  • plugin.ui.shell inspect / debug tab
  • 插件 UI 不离开 chrome 进程

Host · L2 缝

  • contribute_* / execute / withdraw
  • present / playback / export frame
  • has_capability 查不透明表

Embed · 解释器

  • PythonRuntime isolated CPython 3.12
  • 按目录加载 plugin.py（不抢 plugin 名）
  • eval 给 Console :py

L1 · 能力底物

  • plugin.scene3d / plugin.map2d
  • run_processing → native.* / product ids
  • Python 只编排，不实现 TIN/GEOS

原理流：启用一个 Python 包

1Registry set_enabled
→
2PythonRuntime::start(dir, entry)
→
3importlib 独立模块名
→
4start(host) 贡献 command/dock/processing
→
5菜单 / Console 调 L1 ids

停用：chrome withdraw(plugin_id) 再 stop(directory)。samples 在 runtime/python/samples/（hello / analysis / product_orchestrate / industry_pack）。
