codegen — GIS IR

套件 .py 先变成 app::code 的直线模块，再按方言落到现有标准库。app::ir 的函数签名保持不动。

规格：views desktop shell §Codegen GIS IR

流水线

1 语法

codegen/front
Python3 ANTLR → 自有 AST。第一处语法错误即停。

2 语义

codegen/sema
子集、sg、动词、槽。有错不出模块，不碰 Host。

3 Codegen

codegen/lower
收成 Module。不链接 backend。

4 执行

codegen/eval
按 OpDesc 下标调用。第一条失败即停，不回滚。

5 宿主

session 先 bind。app::ir 与 GEOS / PROJ 在执行时才进入。

语义失败时，令牌停在第 2 步，Host 不会亮。

五种方言

Geo谓词、构型、坐标变换。操作在 IL。求值调用 geometry_traits、GEOS、PROJ。几何是字符串池里的 WKT，crs_epsg 在操作数上。
RelationScan / Filter / Project / Join / Aggregate。空集是成功。
Map文档、图层、要素、样式、导出。有顺序。
Process具名过程与 Scenario。端口类型固定。
Sessionpump、mark、指针、等待、断言。
Geo → geometry_traits / GEOS / PROJ
Relation → MapLayer 迭代
Map → app::ir document / view
Process → run_processing / try_exec_harness_op
Session → app::ir horizon / gesture

同一份模块可以按脚本顺序混合 Map、Process、Session。Geo 与 Relation 的操作在 IL 里求值。插件不提供 GIS 对象 API。

插件

IL Geo / Relation / Map 操作。主入口是 IL runtime。套件脚本和以后的产品脚本从这里进来。
语言扩展 + 执行扩展 plugin/runtime/python 只把额外表面 lower 成 IL 操作，并为自己拥有的 op 提供 eval。GIS 类型不登记在绑定里。控制台任意 :py 仍是嵌入式 CPython。
