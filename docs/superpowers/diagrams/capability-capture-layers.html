horizon 里的 capture 分层

这些文件在 backend/runtime/horizon，不再有并列的 capture/ 目录。bind/bind.h 同时声明 bind_export。编译相位仍是 bind 接槽，sema 做语义与编排，atom 只做一步机器操作。命名空间保持 app::detail。atom 不包含 sema。

1. 层（谁拥有什么）

bind — 链接

  • bind/bind 只接 export_bmp，转给 sema/export。

sema — 语义

  • env 解析 GPU / linger 开关。gate 判定亮部、色差、均值。frame 把导出帧名落到相机。
  • read 决定重试与 PrintWindow→BitBlt。session 选择借壳或自建设备。warmup 跑多帧。
  • capture 编排一次 Scene3D 抓图。export 在 GPU 帧与软件 hypsometric 之间选择。finish 决定借壳是否只停表。

atom — 原子操作

  • bmp 写文件。mark 写标记。window 建/拆 present HWND。gdi 一次 PrintWindow、BitBlt、GetDIBits、StretchBlt。
  • host 停表、detach、踢一帧、present_gpu 一次。paint 一次软件 hypsometric。

2. 原理流（一次 Scene3D 抓图）

env 解析开关，不建 Device。gate 只回答「这帧算不算亮」，不抓 HWND。
