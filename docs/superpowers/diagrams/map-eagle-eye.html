2D 鹰眼（Overview）

M1 + 重构：kernel LayeredPopupHost 共用 DXGI overlay sync；鹰眼拆 geom / persist / paint / input。图：map-eagle-eye.html

分层

UI · kernel overlay

LayeredPopupHost：child 或 layered popup；已请求几何 + 禁滥用 SWP_SHOWWINDOW。鹰眼与 identity HUD 共用。

UI · eagle_eye

EagleEyeHost 门面；geom / paint / input / persist；View 菜单开关。

Present · 主图

FlyCube / DXGI 仍是 SoT；鹰眼不跑第二套 map present（M1）。

原理流

  1. 主图范围变化 → Browser::push_shared_extent 写入鹰眼 world/view 并 sync_eagle_eye。
  2. 用户在鹰眼内导航 → commit 回调改 ViewFrame → 再 push，主图 DXGI present。
  3. M2：同一控件可贴低频缩略图层；仍不常驻第二 DrawHost。
