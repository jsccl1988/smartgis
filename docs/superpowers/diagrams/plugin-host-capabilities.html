content::PluginHost 通用能力表

内容公共 API 只做贡献点 + 不透明 set_capability / query_capability。产品插件名与 Scene3D / Report 门面在 plugin_host.dll 与 chrome 注册，不进 content/public/plugin_host.h。

分层（谁拥有什么）

content.dll

PluginHost：command / menu / dock / dialog / processing / painter / present_dataset / playback / export_frame

能力表：id → void*，不解读 id，不向下转型

plugin_host.dll + chrome

表：plugin/runtime/host/capability/capability.h（HostCapabilities::attach）

门面：capability/scene3d/sink.h · capability/report/bridge.h

池：processing/processing.h → plugin.processing_pool

Gis 辅助仍在 host/present/gis_present.h（不是能力 id）

产品包

plugin::scene3d_sink(host) / report_bridge(host)

world3d / mine / stormsurge / smartgis.self_test 只依赖门面或 contribute_command，不出现在 content 公共头

chrome app/views/runtime/capability/ 保持扁平 binder，不是这张表

原则流（注册 → 查询 → 撤回）

1PluginShell::init 创建 Host，attach 能力袋
→
2chrome 安装 bridges（earth / look / report dock）
→
3产品 contribute_command（含 self_test.*）+ processing 按 id 查询门面
→
4harness 发布 app.views.self_test 后 execute
→
5shutdown detach；content 仍不知道产品名
