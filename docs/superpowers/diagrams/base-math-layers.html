base/math — 场景数学分层

POD 场布局不变（.x / _11.._44）；运算走 Eigen Map。公开命名空间两层止于 base；物理子目录不引入第三语义命名空间。不进 base.dll。

Living：2026-09-14-base-root-hybrid-design.md §Math 分层 · GN //src/base/math:math

1. 核心分层（谁拥有什么）

scalar

  • kPi / kEpsilon
  • deg_to_rad
  • 无 Eigen

linear

  • Vector2/3/4
  • Matrix / Quat
  • Point2 / LpToDp2

traits

  • vector_traits<V>
  • vector_like
  • GIS 再导出 geo::

geom

  • Aabb / Obb
  • Plane / Ray
  • Frustum / cull enum

xform

  • TransformStack
  • lerp / slerp
  • TRS → Matrix

simd

  • batch normalize
  • LP→DP xy batch
  • 默认标量；AVX2 可选
