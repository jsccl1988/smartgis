browser/plugin — 子目录分层

按职责拆 shell/ · host/ · present/ · harness/ · detail/。产品 payload 仍在 src/plugin/product；壳只保留平台与中立 present。

Spec：§browser/plugin subdirectory · 模块：plugin/README.md
相关图： Views 进程 content present 子目录 harness IL

1. 核心分层

shell/ — 平台所有权

  • PluginShell
  • plugins_dir / peek_plugin_startup
  • builtins · pack_enable
  • startup_apply

host/ — PluginHost sinks

  • host_context.h
  • plugin_host_wiring.cc
  • map2d / scene3d bridges
  • horizon 填回调，无 Browser*

present/ — 壳呈现

  • tab / dataset present
  • PluginPlayback
  • PluginPreviewHost
  • 不点名 flood/traffic 存储

harness/ — 套件专用

  • report_suite
  • FakeReportBrowser
  • 不进交互默认路径

detail/ — 共享助手

  • path_resolve
  • exe 相对路径
  • bridges 共用
