Content public embedder — 产品只含公开面

产品（今天 app/views，以及未来 exe）只实现 GisContentsClient 并包含 content/public 的七个既有头。content 不依赖 src/app 或 ui/views。插件只经 PluginHost 进入，不走第二条嵌入轴。

Spec：§Content public embedder · 目录层（另一张图，不在本图重开 C11）：content/browser 责任层
相关： Views shell src/content/README.md

1. 泳道（谁拥有哪一层）

产品 · embedder

  • 今天：app/views（SmartGIS.exe）
  • 未来：另一套壳的 exe，不包含 app/views
  • 实现 GisContentsClient（仅浏览器进程钩子）
  • 运行时调用七个头，不包含实现目录

content/public · 唯一嵌入 API

  • GisContentsClient + content_main(params, GisContentsClient&)
  • GisContents · GisDocument · ToolSession
  • PluginHost · EventBus · types（无 map_bootstrap）
  • 公开头：抽象 GisDocument；具体适配器在 browser/

content 实现 · 产品不可见

  • browser / renderer / view / embed / app
  • renderer / gpu 分发在这一侧完成
  • BrowserSession · ViewFrame · presenter 留在这里
  • CapabilityHost 是 il.runtime 缝，不进 public

3. 阶段

阶段谁在动谁等待谁不 join
1 产品 → content_main(params, GisContentsClient&) 产品停在浏览器进程钩子，直到浏览器循环返回 产品不进入 content/renderer 或 gpu 入口
2 content 读 --type，在实现内部调用 RendererMain / GpuMain 浏览器进程以外，产品客户端不被调用 renderer / gpu 永不 join 产品。GisContentsClient 不声明这两个入口
3 plugin/product → PluginHost 插件命令走宿主回调，不阻塞 content_main 的进程分发 插件 不 join GisContentsClient 轴，也不变成第二个 exe 壳

实线 嵌入合同 虚线 禁止跨层：产品不包含实现目录；renderer/gpu 不回到产品 插件 只接触 PluginHost
