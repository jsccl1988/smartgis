顶层 bootstrap / shell/{frame,catalog,dock,showcase} / views/{document,viewport,helper} / res。Scheme C，无 shim。类 ABI 冻结。dll_stem=app_core 不变。

原则流
  1. win_app InitInstance → App::Init（bootstrap）→ 可选 showcase / self-test 早退。
  2. DelayInit → sample_map 装 china 样例 → 仅 PostMessage 开 Edit。
  3. Edit/Data/3D OnInitialUpdate 共用 views/helper/mdi_menu（legacy_app::helper）；光标状态栏走 views/helper/status_coord。
  4. 顶层四目录；shell/ 与 views/ 均按职责分子目录；showcase stem 用 *_showcase，与 scene3d_view 分离。
