analysis 内核分层

样板：src/gis/analysis/geochem/ · 约定可复用到其它 analysis 域 · catalog id / JSON 合同不变

1. 核心分层（依赖只向下）

op — catalog 调度 op/stats_op · op/idw_op · 只用 ops_args 解析 JSON，组合 load + kernel + io
codec / io — 编解码 load/csv_load · load/vector_load · io/geotiff（GDAL 出入）
kernel — 纯计算 stats/ · idw/ · grade/（无 rapidjson、无 GeoTIFF Driver）
model — 纯数据 model/sample：GeochemSample(Set) · element_index · values_for_element

禁止：kernel → op；kernel → GDAL Driver 写出；op 内复制 JSON 解析（复用 ops/runner/ops_args）。

2. 原理流（native.geochem_idw）

JSON args → op::run_idw_op → load_csv → run_idw → write_idw_geotiff
plugin/product/geochem → model + load + kernel（可直调，不经 JSON） → present

ops_runner 只 include op/*；产品包可组合内核，不必走 catalog。

3. 共享脚手架

  • ops/runner/ops_args：decode_op_args / op_arg_string / op_arg_double / op_arg_int
  • 不新建第二套 op 注册表；catalog id 仍由 ops_catalog + run_builtin_op 分支调度
  • 其它 analysis 域（geology / raster…）按需照抄目录形状，不强制一次迁完
