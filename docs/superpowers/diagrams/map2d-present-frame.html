2. 原理流：MapScene → MapFrame → 两个出口

两条出口读同一份 DrawItem / DrawBlend。equal-profile 的 warm-GPU / paint_ms 预算不在这张图里；那些格子使用 MAP2D_NO_HILLSHADE=1，不能当作晕渲一致性证明。

2b. Scenic rhi2d（app 可选栈）

默认仍是上图 Vista MapFrame 双出口。MAP2D_ENGINE=scenic 时 Views 地图 HWND 走 Scenic rhi2d：ScenicRhi2dHost → Renderer2d + gis::Map + scenic_rhi2d_{gdi,gdiplus,skia}（RHI2D_PORT）。这不是 MapFrame 出口，也不使用冻结的 src/legacy。

3. 层与职责

层拥有
content presentMap2dPresenter、PresentAction、snapshot_present、Map2dGpuPresent、phase profile、GDI FillBatch / DcStyle / BitBlt 缓存；map2d/{frame,gpu,software,scenic}
gis vista + cartoLayout::build、default_carto_style_json、collision、线/注记/批次策略、shade_dem_rgba、bake_hillshade_slot
effect mapDrawItem → 命令列表；DrawBlend → BlendMode
software GDI按 DrawItem 的 blend 填三角、画定位字形、贴光栅。kIcon 在产品样式发出图标之前可以空操作

gis/style 仍是 StyleDocument / ResolvedPaint / 表达式，不是批次或描边策略的家。软件入口不是 src/legacy/render/rhi2d 的 PaintBackend。
