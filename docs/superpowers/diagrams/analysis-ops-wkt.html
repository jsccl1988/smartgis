analysis ops：深度分层

几何功能体在 geo::。analysis/ops 只做边界、薄目录与域静态表。

边界

wkt_ops / glang / plugin::run_builtin_op 保持稳定签名。CRS 检查与文本进出只在边界。

编解码 · 要素

ops/wkt · ops/geojson 做文本 ↔ OGRGeometry。ops/features 做扫描 / 过滤 / 投影（迁出原 ops/ir）。

薄 IR 目录

ops/ir：eval_geometry_ir 按 native.* id 调 geo::*。无 GEOS 实现副本。

功能体 geo::

buffer / set / shape（GEOS）· predicate / measure（OGR）· transform（PROJ）。traits 约束 ogr_geometry_like。

域静态表

各域 const BuiltinOpEntry[]；ops/runner 链成只读总表。无运行期 register、无 GetProcAddress。

边界→ codec / features / runner→ 薄 IR→ geo:: 功能体→ OGR / GEOS / PROJ
  1. 几何文件 op：GeoJSON 解码 → apply_op → eval_geometry_ir → geo::* → 编码。
  2. WKT / glang：编解码 + 同一 IR 节点。
  3. 域内核：表查找 run_*_op，不经几何 IR。
