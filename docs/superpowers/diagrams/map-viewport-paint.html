1. 责任分层

UI · wnd_proc

Timer / WM_PAINT / size / capture。不直接调 GPU Present。

CPU · present + overlay

3D 才 blit SharedSurface。2D 只跑 Map2dPresenter / Scene3dPresenter。

GPU · display / gpu_present

Display 线程独占 rhi::Device。Scenic 2D 禁止这条 DXGI 路径。

Shell · HUD / overlay

Identity HUD + DrawRequest.shell。Chrome 像素不得盖住地图。
