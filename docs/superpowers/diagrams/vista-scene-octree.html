Vista GpuScene — 开源 octree 场景与 mesh 索引

逻辑 World 与 GPU GpuMesh 各持一份 unibn 点 octree（AABB 中心）。录制前用视锥包围球做候选，再用平面精确过滤场景外物体。

Spec：§Vista scene unibn octree · 代码：src/vista/scene/index/ · 上游：jbehley/octree（unibn::Octree）

1. 核心分层

逻辑 — instance_index_

  • sync 复制 World → GpuInstance
  • kind_tess / tessellate 出 CPU 网格
  • AabbOctree 索引 AABB 中心
  • scene_cpu_sources 不依赖 render

物理 mesh — mesh_index_

  • gpu_mesh.h 持有 VB/IB
  • rebuild 调 upload_mesh
  • 点云 chunk 独立 AABB
  • frustum_camera 把 CameraMatrices 写成 POD

录制 — 场景外过滤

  • prep_cull 只写 MeshCullItem / visible[]
  • 视锥世界 AABB + 半径候选
  • record_kind 串行读标位
  • 工人禁止 Device / CommandList

2. 原理流

绿 = CPU 索引 / 剔除；琥珀 = GPU 上传与录制。工人不碰 CommandList。

半径查询是保守的（视锥 AABB 半对角 + 最大 mesh 半对角）。漏检由精确平面测试兜底过滤假阳性；视锥 AABB 求逆失败时回退线性扫描。

3. 边界

做不做
产品 vista/scene/index 适配器；leftover SmtSceneOctTree 不进本 DLL 不把 Octree.hpp 放进公开头；不做 GPU BVH / occupancy
默认视锥仍关（DEM AABB 历史问题）；opt-in 与 prep 并行诚实门不变 不替换 World::query_aabb 的线性实现（仍可后接）
