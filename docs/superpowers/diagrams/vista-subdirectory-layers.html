vista.dll — 深度抽象分层与子目录

视口景象层：CPU 布局 / World 与 GPU pass 同 PE，gis ↛ vista ↛ leftover。上一代对照轨 Scenic（src/scenic / scenic.dll，宿主 content；leftover render 冻结）。Include 一律 vista/<module>/…。

相关图： GIS MapFrame Map2d present A×B 并行 Scenic leftover render

1. 核心分层（谁拥有什么）

gis.dll

  • 拥有：model / carto / geo / analysis
  • 不拥有：MapFrame、World、RHI pass
  • 硬墙：↛ vista.dll、↛ render/rhi

vista CPU（同 DLL）

  • frame/ — Layout → MapFrame
  • world/ — 逻辑节点 / DEM / tess / 点云
  • assets/ — ModelAsset / Tileset
  • domain/ — DomainSession + CPU atmosphere
  • 不拥有：CommandList、HWND、Views

vista GPU（同 DLL）

  • map/ — vista::Pass 消费 DrawItem
  • scene/ — GpuScene sync_from World
  • atmosphere/ — AtmosphereFrame + passes
  • 不拥有：StyleDocument、OGR 打开、chrome

render / content / leftover

  • render：rhi + graph 编排；↛ map/scene 头
  • content present：双出口消费 MapFrame / GpuScene
  • legacy/gis/vista：DEM 适配，编进 vista.dll（不是 Scenic）
  • Scenic：src/scenic / scenic.dll；leftover src/legacy/render 冻结；不进 vista.dll
  • 产品 TU 禁止 #include "legacy/…"

2. 原理流（LayerBatch → present；World → GpuScene）

虚线箭头为 Map2d 主路径（Layout → Pass → present）。World → GpuScene 与 AtmosphereFrame 是 Scene3d 并行出口，不回流 gis.dll。

路径职责公开命名空间
