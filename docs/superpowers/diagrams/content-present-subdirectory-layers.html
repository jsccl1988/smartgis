1. 核心分层

host/ — 共享表面

  • blit/ — BlitFrameCache
  • overlay/ — ShellOverlayEffect
  • scenic/ — GisScene → scenic POD
  • gdi/ — 薄 Win32 助手（非 SoT）

facade — 车道根

  • map2d_presenter.*
  • scene3d_presenter.*
  • */profile/*_phase_profile.*
  • scene3d/session/ · atmosphere/
  • scene3d/scenic/ — Engine host

frame/<role>/ — CPU IR

  • map2d：cache · carto · batches · layout · tile
  • scene3d：orbit · terrain · tileset · overlay
  • 只产 MapIR / World 输入，不录 CommandList

gpu/ — 设备出口

  • present/ — MapPass / WorldPass
  • map2d selection/ — flash / pick MapIR
  • 无 soft HDC 出口

2. 原则流（一帧）

动画按阶段点亮：谁准备 IR、谁录 CL、谁碰 HWND。GPU 车道从不回写 soft HDC。
