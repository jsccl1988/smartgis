gis/geo — 现代几何体分层与原理流

OGR 拥有 OGC 矢量几何（TIN = OGRTriangulatedSurface）；geo::Grid 只作 2D 计算缓冲；3D hex 仅 plugin/product/world3d/hexgrid HexLattice（OGRMultiPoint XYZ + nx/ny/nz）；geo::Tin 弃用门面；geo/proj 做 CRS；geo/tin 做非结构化 mesh 生成；geo/grid 做结构化椭圆光滑；traits 统一实例 coordinate_dimension；ops / codec / present 严格分界。

1. 核心分层（谁拥有什么）

Types

  • OGC：OGRGeometry / OGRTriangulatedSurface
  • Mesh：Grid（2D）；Tin 弃用；3D hex 仅插件
  • Vector：render::VectorN
  • 单层次；无 Geometry2/3

Traits

  • geometry_traits<G>
  • geometry_like / ogr_geometry_like
  • vector_traits（compile-time）
  • mesh 特化挂同一 traits

Ops

  • geo::buffer → GEOS/OGR
  • geo::delaunay（GEOS XY）
  • geo::solve_laplace / solve_elliptic / compute_orthogonality
  • geo::CoordinateTransform

Codec

  • 薄 indexed_tin（add_patch）
  • WKB/WKT = OGR
  • Feature = datasource
  • kernel 不重写编解码

Present

  • vista tessellate_*
  • frame layout → DrawItem
  • content / effect 消费
  • kernel ⊥ UI/RHI
