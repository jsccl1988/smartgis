app/views/runtime — 子目录与流水线

Views 壳 runtime 三个对等目录：capability/ 填 Host 并跑脚本； interact/ 解析并执行 Interact.g4；plugin/ 是插件无关的 present / playback / preview 缝。 产品 payload 仍在 src/plugin/product，不进本树。

Spec：§Harness capability runtime · 插件缝：plugin-host-design · As-built：src-layout
相关图： Views shell content/browser analysis processing

1. 核心分层

capability/ — 入口

  • fill_host 只编排 binder：shell / session / paths / export / plugin
  • run_script：解析 suite *.il 路径并调用 apply
  • DebugAgent script.run 只走 Host 回调

interact/ — DSL

  • 根：apply（公共入口，组合各层）
  • wire/ AST+parse · policy/ args · io/ 文件+HWND · host/ Host 适配
  • exec/：horizon / document / plugin / showcase / input
  • ANTLR gen 在 out/*/gen，不入库

plugin/ — 壳缝

  • present：主视图 / preview 数据集
  • playback：插件无关 ResultPlayback 时钟
  • preview_host：surface=1 Map/World preview
  • 不出现 flood / traffic / orthogrid 名字

content Host — 动词袋

  • content/browser/capability/
  • 无 app/views 依赖
  • Scene3dSink 安装在 browser/plugin/plugin_host_wiring.cc
