il.runtime — 子目录与流水线

Interact Language runtime（src/app/views/il.runtime）按编译器相位分层： language/ 是驱动（源文件 + 选前端 + session 链接）； frontend/ 是 Interact.g4 + AST + parse； backend/ 打平：:compile 降级解释，:capability 填 Host； ir/ 是语言无关指令。 插件无关的 present / playback / preview 缝在 browser/plugin/。 产品 payload 仍在 src/plugin/product，不进本树。

相关图： Harness → capability 锁定切分 Views shell content/browser analysis processing

1. 核心分层

language/ — 驱动

  • load：源文件查找，不碰 Host
  • driver：按后缀选 .il / .json / .py
  • run_script：链接一次再 apply
  • 不 include capability/（session / panel 除外）

execution/ — IL 前端

  • front/：lex + parse → AST
  • sema/：绑定参数，降成 Action
  • eval/：跑动作和 seq / repeat / chord
  • ANTLR gen 在 out/*/gen，不入库

capability/ — 运行时

  • link/bind_host 链接器
  • packs：horizon/ · capture/ · plugin/ · expect/
  • 不解析 *.il；不 include language/
  • GN :capability 不依赖 :execution / :ir

content Host — 动词袋

  • content/browser/capability/
  • 无 app/views 依赖
  • Scene3dSink 安装在 browser/plugin/plugin_host_wiring.cc
