il.runtime — 四个对象

Interact Language（src/app/views/il.runtime）与 content::CapabilityHost 使用同一组对象： document、view、plugin、horizon。 frontend/ 解析，ir/ 发指令，codegen/ 降级， backend/ 填槽。view 覆盖 edit / data / scene，以及以后的 world 视口。 产品 payload 仍在 src/plugin/product。

Spec：§Harness capability runtime · 插件缝：plugin-host-design · As-built：src-layout
相关图： Harness → capability 锁定切分 Views shell content/browser analysis processing

1. 核心分层

document

  • 图层、要素、样式、范围
  • 打开 / 保存 / export_bmp
  • 端口 DocumentCapability

view

  • 任一 ViewKind：edit、data、scene、以后的 world
  • present、编辑输入、工具、静帧
  • 端口 ViewCapability。内部分层见下节

plugin

  • 命令、处理、路径、回放、报告
  • 端口 PluginCapability

horizon

  • 壳：时钟、页签、注入、布局、控制台
  • 端口 HorizonCapability
  • fail_rc 留在 Host 上
