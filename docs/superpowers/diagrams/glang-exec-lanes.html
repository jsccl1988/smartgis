glang exec 三车道

解释器只认一张动词表。脚本调用和 GIS 调用都汇入 invoke_inst。

py · 嵌入exec/py：CPython、套件装载、glang.ext、embed。只组参数，不复制操作码表。
vm · 虚拟机exec/vm：动词表（内建槽、动态名、exec 扩展、语言降级）和 invoke_inst。
op · 功能体exec/op：拆操作数后直接调 CapabilityHost。几何内核在 exec/op/gis/geom。
host · 宿主glang.runtime/host：把 content::Shell 填进能力槽，并登记动词。不经过单独的 ir 层。
