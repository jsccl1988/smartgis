DLL / STL 信任模型

仓内产品 DLL 同构（Chromium component 式）可传 STL；插件 / 脚本 / 第三方走扁平 ABI。Export 只服务链接，不等于公共 API。

规范：specs/2026-09-14-base-root-hybrid-design.md §DLL / STL trust · 门禁：build/tools/check_dll_homogeneity.py（stem + SMARTGIS_BUILD_ID）· 链接：detect_mismatch

四类边界

A · 仓内产品

  • base / gis / content / render / vista / ui_views / tool / net / plugin_host …
  • 同 out/Debug|Release、同 /MD(d)
  • 允许 std::string / vector

B · 稳定嵌入面

  • content/public
  • 虚接口；新 API 优先 string_view / span / POD
  • 实现可厚，契约保持瘦

C · 插件 / 脚本

  • glang ext · plugin.json · GetProcAddress
  • 禁止 STL 进出
  • opaque handle / C 缓冲 / 序列化

D · 第三方预编译

  • CPython（Debug 桩）· 闭源 GPU
  • 隔离或 stub；不混堆
  • 对齐 PA-E / CRT 同构
