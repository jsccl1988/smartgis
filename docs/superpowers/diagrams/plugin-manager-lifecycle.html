插件管理器生命周期

Chrome 拥有 plugin::PluginManager（非进程单例）。产品 DLL 导出 init / run / destroy。不改 content/public/plugin_host.h。

分层（谁拥有什么）

Horizon UI

app::PluginCatalogView：列表 + 悬停 tooltip

PluginShell::show_manager 模态框

扫描根：<exe>/plugins（out/Debug/plugins 或 out/Release/plugins）

产品 / harness 启动只读 plugin.json 的 startup（含 scenario）。差异化测试改 out/Debug/plugins/flood/plugin.json

plugin_host.dll

PluginManager scan → LoadLibrary → init

Registry enable/disable / trust

C ABI：init(void* host) · run(event, payload) · destroy()

content.dll

既有 PluginHost 贡献点（command / processing）

不识别插件包名；不新增 public 方法

产品包 → 独立 DLL（锁定）

扫描 out/<config>/plugins/<package>/plugin.json（kind=native + library）。GN 目标 *_native。不把产品包链进 chrome 作为唯一加载路径。
