1. 核心分层

app/startup — 登记表

  • browser_main / startup/policy 在 Browser 之前读 LaunchPolicy
  • 一行：{id, mark_leaf, LaunchPolicy, suite_id}
  • 入口 run_scenario → suite script
  • report_suite 在 browser/plugin

*.il — 编排

  • browser.harness.il 取代 pipeline.cc
  • browser.input.il 已是正文
  • browser.map2d.browse.il / browser.world3d.browse.il 含 seed、静帧、fps
  • ui.shell|data|scene|catalog.il；ui.interact.host.il 包手势脚本

execution — 解释

  • front/ 语法 → sema/ 绑定 → eval/ 解释
  • eval/ 只跑动作和 seq
  • 不 #include Browser

CapabilityHost — 槽

  • content/browser/capability/host.h
  • 只加原子 std::function
  • 不改 content/public
  • 不加 ui_run(mode)

capability — 原语

  • horizon/{bind,sema,atom}（path + inject 在 atom）capture plugin expect/{bind,sema}
  • capture/：bind → sema → atom（语义不进原子操作）
  • horizon/sema 编排 still / china / ui，调用 capture 与 expect
  • expect/：wait / geom / layout / DebugAgent（bind_expect）；编排在 *.il
  • 不再 #include app/startup/scenario.h 或 execution/

2. 原理流（谁先跑、谁不 join）

虚线是控制流，不是 GPU 提交。同一次 apply 在 UI 线程串行走 stmt。
