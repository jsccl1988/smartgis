Map2d 装饰面板

对齐 Atmosphere：右侧 Inspector 只发开关，绘制仍在 map2d furniture。鹰眼仅占位。

分层

UIui/gis/shell/map_furniture_panel — Scale bar / North arrow / Border；Eagle eye set_enabled(false)。不 include map2d / vista。
插件 / Sinkcartography/panel.cc 贡献 dock map2d.furniture 与命令 map2d.furniture_panel。Map2dSink::set_furniture 后 invalidate()。
绘制shell bridge 把 FurnitureOptions 写入 pyramid session。paint_furniture 按 flag 画边框、比例尺、指北。bridge 已安装时绘制读 Sink。

开关到重绘

  1. 勾选变化：面板回调，不直接画地图。
  2. Map2dSink::set_furniture 记下三项 flag，并调用 shell bridge。
  3. bridge 写入 pyramid session 的 FurnitureOptions（默认全开，仅进程内）。
  4. invalidate() 走现有 map2d 路径；paint_furniture 跳过关掉的件。鹰眼不参与。

动画只标出谁在等下一步。鹰眼没有第 5 步。
