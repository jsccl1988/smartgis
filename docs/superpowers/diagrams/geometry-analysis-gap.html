1. 核心分层（谁拥有什么）

Algorithm / gis.analysis

  • GEOS 单几何：geo::{set,shape,…} + 薄 IR + native.*
  • Eigen 拟合：analysis/geometry
  • Delaunay：gis/geo/tin
  • 不拥有 EditSession / UI 面板

Plugin Processing + 图层

  • 转发：plugin::run_builtin_op
  • 图层 dissolve / join / overlay：产品面 + 调内核
  • 禁止平行 Shapely / 插件内第二套核

Tool / EditSession

  • 捕捉：vertex/edge（Map2D P0-4 已绿）
  • 拓扑规则：叠盖/缝隙校验与报告
  • 规则引擎不进 analysis/topology/

2. 原理流（分期）

P0 GEOS 暴露MakeValid · densify · offset · Voronoi · Hausdorff · unary_union…
→
P1 产品主路径dissolve · spatial join · overlay · Eigen align/affine · catalog
→
P2 拓扑EditSession 叠盖/缝隙 · FeatureInfo 报告 · 高级规则后置
→
验收pin checkbox + matrix §9 回写 · 无第二 GEOS

动画：仅高亮当前阶段；P0 不依赖图层会话，P2 不新建算法 DLL。
