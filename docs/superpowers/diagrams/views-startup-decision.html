Views 冷启动决策

Bare SmartGIS.exe 永远走产品策略；场景 demo 只经面板 Run 或 CI 显式 HARNESS_SUITE。

Living: Views §Cold start product-only · Plugin-host §plugin.json startup · 2026-10-13

三入口分层

1. 产品冷启动

  • parse_views_launch_options：仅 host flags
  • product_startup_policy()
  • DefaultChina + run_loop
  • 不读 scenario_id / *SHOWCASE*

2. 面板 Run

  • PluginCatalogView Enable / Disable / Run
  • find_scenario → run_scenario
  • 进程保持交互，不 Terminate

3. CI 显式 API

  • 先 bare 启动（同产品策略）
  • show 后读 HARNESS_SUITE
  • exit_after_scenario
  • 禁止 set *SHOWCASE*

原则流（谁决策 / 谁永不碰冷启动）

实线：冷启动主路径。虚线：产品 show 之后的显式 demo / CI，不改变 LaunchPolicy 选择。
