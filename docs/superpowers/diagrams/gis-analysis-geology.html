gis/analysis/geology — 分层与原理流

地层分析：model / io / kernel / op 四层；纯 XY 几何下沉 gis/geo/xy；Delaunay 复用 geo::delaunay。Processing id 不变。

1. 核心分层

model

  • BoreholeContact
  • BoreholeSet
  • 纯数据，无 I/O

io

  • load_boreholes_csv
  • CSV → BoreholeSet
  • 不碰算法

kernel

  • interpolate_stratum_tin
  • prism_volume_between
  • 只编排地层语义

op

  • run_stratum_*_op
  • JSON args ↔ 文件
  • native.stratum_*
gis/geo（下沉） — geo::delaunay_triangles（tin）· geo::convex_hull_xy / polygon_area_xy / bbox_area_xy（xy）· 不依赖 analysis/geology

2. 原理流（interpolate）

1CSV / BoreholeSet
→
2按 stratum_id 筛点
→
3geo::delaunay
→
4StratumTin / JSON

棱柱体积：配对厚度 → convex_hull_xy 面积（退化则 bbox）→ volume。
